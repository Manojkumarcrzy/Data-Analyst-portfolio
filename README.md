# Manoj Kumar — Data Analyst Portfolio

A responsive, premium-corporate personal portfolio built with plain HTML, CSS and JavaScript. It is designed for GitHub Pages and does not require a build tool or framework.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, project filters and footer year
- `.nojekyll` — tells GitHub Pages not to process the site with Jekyll

## Before publishing
1. Review every statement in `index.html` and make sure it is accurate and current.
2. Replace the LinkedIn and GitHub homepage links with your exact profile URLs.
3. Confirm that the email address is the one you want to publish publicly.
4. Add genuine project screenshots and links. The four project cards are clearly labelled as portfolio case-study templates; do not present them as completed client work until you have built them.
5. If you want a CV download, add a file named `resume.pdf` to this folder and add a link to it in the page.
6. Check the certification title and add a credential verification link if you have one.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload all files from this folder to the repository root. Do not upload the ZIP file as the only item.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to complete. Your website will be available at `https://YOUR-USERNAME.github.io/`.

## Test locally
Open `index.html` in a browser. For a closer local-server preview, use VS Code's Live Server extension.

## Privacy and accuracy
This is a public website. Publish only contact information and work details you are comfortable making public. Do not upload confidential employer data, internal dashboards, customer information or proprietary screenshots. Use synthetic or public datasets for demonstrations.
